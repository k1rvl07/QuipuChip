# Мастер-словарь QuipuChip: 4096 реальных английских слов по 5 букв.
#
# Отбор (повторяем, источник закреплён в Git):
#   1. Кандидаты — словари Wordle (NYT): список допустимых догадок плюс ответы,
#      12971 слово от 12 января 2022 г. (референс: github.com/dfm/wordle,
#      src/words.txt). Список курируемый: в нём нет имён собственных и
#      обсценной лексики, поэтому пайплайн не возвращает «david», «tokyo»
#      или «doesn».
#   2. Ранг каждого слова — частота в en_full (hermitdave/FrequencyWords,
#      content/2018/en/en_full.txt, лицензия MIT): насколько часто слово
#      реально встречается в английском тексте.
#   3. Выбираются 4096 слов с наибольшей частотой. Частотный порядок значит,
#      что в словарь в первую очередь попадают самые узнаваемые слова, а не
#      случайный срез.
#   4. Фильтры как в scripts/wordlist.py: 5 букв a-z, уникальность,
#      BLOCK_SUBSTRINGS, отдельные слова из WORD_EXCLUDE.
#
# Чем это отличается от старого словаря:
#   * слова РЕАЛЬНЫЕ и произносимые, их можно прочитать и переписать;
#   * гарантии расстояния Хэмминга >= 3 больше НЕТ — среди реальных слов это
#     доказуемо недостижимо. Промах в одной букве теперь может дать другое
#     слово словаря. Значит ли это потерять данные? Нет: пароль и так
#     покрыт ошибкой → неверной сверкой. Раньше опечатка в 1-2 буквы
#     превращалась в «правильно выглядящий» неверный пароль; теперь список
#     не криптографический, а выдаваемый пользователю, и риск прочитан и
#     принят владельцем. Подробности в AGENTS.md.
#   * слово, добавленное в этот файл вручную, обязано пройти валидатор
#     (count/длина/уникальность/запрещённые), иначе core не соберётся на
#     --check.
#
# Формат: одно слово на строку, порядок — убывание частоты.
# Изменения — только через перегенерацию из источников или с правкой вручную
# + cargo test -p pm-core и python3 scripts/wordlist.py --check.
#
# Источники:
