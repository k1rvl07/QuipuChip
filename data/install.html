Install Certificate QuipuChip

The device uses its own root certificate (CA). To open https://192.168.7.1/ in your browser without warnings, add this certificate to your trusted store. Until then, only this page is available over the network.

Linux — Chrome / Chromium (через NSS)
  1. Install certutil: в Arch/CachyOS — пакет nss, в Debian/Ubuntu — libnss3-tools.
  2. Add the certificate в хранилище NSS браузера (файл .crt — это DER): 
    certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "QuipuChip CA" -i QuipuChip-CA.crt
    If you use the QuipuChip-CA.pem file, add the -a flag.
  3. Or via UI: open chrome://settings/certificates → Authorities → Import → select QuipuChip-CA.crt and trust for websites.
  4. Полностью перезапустите Chrome.
Linux — системное хранилище (curl, openssl и др.)
  1. Arch / CachyOS / Manjaro: 
    sudo trust anchor QuipuChip-CA.crt
    Or place the certificate in /etc/ca-certificates/trust-source/anchors/ and run sudo update-ca-trust.
  2. Debian / Ubuntu: 
    sudo mkdir -p /usr/local/share/ca-certificates
sudo cp QuipuChip-CA.crt /usr/local/share/ca-certificates/QuipuChip-CA.crt
sudo update-ca-certificates
  3. Fedora / RHEL: 
    sudo cp QuipuChip-CA.pem /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
Firefox (любая ОС)
  1. Open about:preferences#privacy → Certificates → View Certificates.
  2. Раздел «Центры сертификации» → «Импортировать» → выберите QuipuChip-CA.pem.
  3. Отметьте «Доверять при идентификации веб-сайтов» и подтвердите.
Windows — Chrome / Edge
  1. Double-click QuipuChip-CA.crt → Install Certificate.
  2. Разместите его в хранилище «Доверенные корневые центры сертификации».
  3. Либо из командной строки: 
    certutil -addstore -user Root QuipuChip-CA.crt
  4. Перезапустите браузер.
macOS — Chrome / Safari
  1. Double-click QuipuChip-CA.pem and add it to the "System" or "Login" keychain.
  2. In Keychain Access, open the certificate, go to "Trust", and set "When using this certificate" to "Always Trust".
  3. Or from terminal: 
    sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain QuipuChip-CA.pem
Android
  1. Download QuipuChip-CA.crt to your device.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Confirm the warning and select the downloaded file.
iOS / iPadOS
  1. Download QuipuChip-CA.crt and open it.
  2. Settings → General → VPN & Device Management → install the profile.
  3. Settings → General → About → Certificate Trust Settings → enable full trust.
Certificate reissued (after erasing tls partition)
  1. The CA is stored on the device and only changes when the tls partition is erased. After that, the old certificate is no longer trusted and your browser will show a warning again.
  2. First check the SHA-256 fingerprint above: if it changed, remove the old CA and import the new one. Importing with the same name "QuipuChip CA" without removing the old one may fail.
  3. Linux — Chrome / Chromium (NSS): remove old and add new: 
    certutil -d sql:$HOME/.pki/nssdb -D -n "QuipuChip CA"
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "QuipuChip CA" -i QuipuChip-CA.crt
  4. Linux — системное хранилище (Arch / CachyOS / Manjaro): 
    sudo trust anchor --remove QuipuChip-CA.crt
sudo update-ca-trust
    If the cert was placed in /etc/ca-certificates/trust-source/anchors/, remove the file there and run sudo update-ca-trust.
  5. Linux — системное хранилище (Debian / Ubuntu): 
    sudo rm /usr/local/share/ca-certificates/QuipuChip-CA.crt
sudo update-ca-certificates
  6. Linux — системное хранилище (Fedora / RHEL): 
    sudo rm /etc/pki/ca-trust/source/anchors/QuipuChip-CA.pem
sudo update-ca-trust
  7. Windows: certutil -delstore -user Root "QuipuChip CA" for current user or certutil -delstore Root "QuipuChip CA" as administrator.
  8. Firefox: remove in about:preferences#privacy → Certificates → View Certificates → Authorities → select QuipuChip CA → Delete, then import the new one.

After installing, open https://192.168.7.1/ — the certificate is issued for this IP address.
