Установка сертификата PassManager

Устройство использует собственный корневой сертификат (CA). Чтобы браузер открывал https://192.168.7.1/ без предупреждения, добавьте этот сертификат в доверенные на своём компьютере. До этого веб-интерфейс хранилища по сети недоступен — отдаётся только эта страница.

Скачать PEM Скачать CRT (DER)
SHA-256 отпечаток CA:
Linux — Chrome / Chromium (через NSS)
  1. Установите утилиту certutil: в Arch/CachyOS — пакет nss, в Debian/Ubuntu — libnss3-tools.
  2. Добавьте сертификат в хранилище NSS браузера (файл .crt — это DER): 
    certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "PassManager CA" -i PassManager-CA.crt
    Если используете файл PassManager-CA.pem, добавьте флаг -a.
  3. Либо через интерфейс: откройте chrome://settings/certificates → «Центры сертификации» → «Импорт» → выберите PassManager-CA.crt и включите доверие к сайтам.
  4. Полностью перезапустите Chrome.
Linux — системное хранилище (curl, openssl и др.)
  1. Arch / CachyOS / Manjaro: 
    sudo trust anchor PassManager-CA.crt
    Или положите сертификат в /etc/ca-certificates/trust-source/anchors/ и выполните sudo update-ca-trust.
  2. Debian / Ubuntu: 
    sudo mkdir -p /usr/local/share/ca-certificates
sudo cp PassManager-CA.crt /usr/local/share/ca-certificates/PassManager-CA.crt
sudo update-ca-certificates
  3. Fedora / RHEL: 
    sudo cp PassManager-CA.pem /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
Firefox (любая ОС)
  1. Откройте about:preferences#privacy → «Сертификаты» → «Просмотр сертификатов».
  2. Раздел «Центры сертификации» → «Импортировать» → выберите PassManager-CA.pem.
  3. Отметьте «Доверять при идентификации веб-сайтов» и подтвердите.
Windows — Chrome / Edge
  1. Дважды щёлкните PassManager-CA.crt → «Установить сертификат».
  2. Разместите его в хранилище «Доверенные корневые центры сертификации».
  3. Либо из командной строки: 
    certutil -addstore -user Root PassManager-CA.crt
  4. Перезапустите браузер.
macOS — Chrome / Safari
  1. Откройте PassManager-CA.pem двойным щелчком, добавьте в связку «Система» или «Вход».
  2. В «Связке ключей» откройте сертификат, в разделе «Доверие» выберите «Всегда доверять».
  3. Либо из терминала: 
    sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain PassManager-CA.pem
Android
  1. Скачайте PassManager-CA.crt на устройство.
  2. Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → «Сертификат CA».
  3. Подтвердите предупреждение и выберите скачанный файл.
iOS / iPadOS
  1. Скачайте PassManager-CA.crt и откройте его.
  2. Настройки → Основные → VPN и управление устройством → установите профиль.
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите полное доверие.
Сертификат пересоздан (после стирания раздела tls)
  1. CA хранится на устройстве и меняется только при стирании раздела tls. После этого доверие к прежнему сертификату больше не действует, и браузер снова покажет предупреждение.
  2. Сначала сверьте SHA-256 отпечаток выше: если он изменился, старый CA нужно удалить, а затем импортировать новый. Импорт с тем же именем «PassManager CA» без удаления старого может не пройти.
  3. Linux — Chrome / Chromium (NSS): удалить старый и внести новый: 
    certutil -d sql:$HOME/.pki/nssdb -D -n "PassManager CA"
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "PassManager CA" -i PassManager-CA.crt
  4. Linux — системное хранилище (Arch / CachyOS / Manjaro): 
    sudo trust anchor --remove PassManager-CA.crt
sudo update-ca-trust
    Если сертификат был положен в /etc/ca-certificates/trust-source/anchors/, вместо этого удалите файл оттуда и выполните sudo update-ca-trust.
  5. Linux — системное хранилище (Debian / Ubuntu): 
    sudo rm /usr/local/share/ca-certificates/PassManager-CA.crt
sudo update-ca-certificates
  6. Linux — системное хранилище (Fedora / RHEL): 
    sudo rm /etc/pki/ca-trust/source/anchors/PassManager-CA.pem
sudo update-ca-trust
  7. Windows: certutil -delstore -user Root "PassManager CA" для хранилища пользователя или certutil -delstore Root "PassManager CA" от имени администратора.
  8. Firefox: удалить в about:preferences#privacy → «Сертификаты» → «Просмотр сертификатов» → «Центры сертификации» → выбрать PassManager CA → «Удалить», затем импортировать новый.

После установки откройте https://192.168.7.1/ — именно так, сертификат выдан на этот IP-адрес.
